  • 01 軟體工程

    Software Engineering Workshop

    19 個核心主題，從開發基本功到交付部署；每個主題都有教材，以及在瀏覽器內執行的模擬實驗。

    • Git
    • REST API
    • 資料庫
    • 測試
    • Docker
    • CI/CD
    • 部署
    線上可直接使用
    開啟網站→ GitHub ↗
  • 02 AI 安全

    Guardrail Workshop

    LLM 應用的安全防護層：風險、input / output / tool 三個掛載點、框架選型。附互動實驗場，以及可以在本機跑的 FastAPI 縱深防禦服務。

    • Guardrails
    • Prompt injection
    • PII
    • FastAPI
    教材與實驗場線上可用；後端服務需在本機執行
    開啟網站→ GitHub ↗
  • 03 AI Agent

    AI Agent Tutorial

    用 FastAPI、LangChain 與 Dify 練習 AI 應用的組法：REST API、RAG 問答、WebHook 事件，到 Dify 整合。

    • LangChain
    • RAG
    • WebHook
    • Dify
    線上 API 已停用，網站只剩前端畫面；完整功能請依 README 在本機執行
    開啟網站→ GitHub ↗
  • 04 雲端 · AWS

    AWS Lab

    在 AWS 上使用生成式 AI：Bedrock 的呼叫、計費與防護，以及用 IAM、S3 + CloudFront、Lambda 與 GitHub Actions OIDC 把應用安全地放上 AWS。附權限評估、部署計畫等實驗。

    • Bedrock
    • Converse API
    • Guardrails
    • IAM
    • CloudFront
    • Lambda
    • OIDC
    線上可直接使用
    開啟網站→ GitHub ↗
  • 05 程式語言

    語法實戰 Lab

    給已經會其他語言的開發者：邊寫邊跑的練習題，附提示、解答、語言對照，草稿與進度存在瀏覽器裡。

    • TypeScript
    • Go
    • Python
    • FastAPI
    • Pydantic

    • TypeScript Lab

      10 章 40 題，對照 C++、C#、Python；型別檢查與執行測試都在瀏覽器內完成。

      線上可直接使用
      開啟網站→ GitHub ↗

    • Go Lab

      10 章 40 題，Monaco 編輯器與語言對照；練習直接送到 Go 官方編譯服務執行與測試。

      線上可直接使用
      開啟網站→ GitHub ↗

    • FastAPI Learning Lab

      14 個模組、111 堂課，依官方 Learn 導覽編排；練習在瀏覽器內以 Pyodide 執行並自動檢查。

      線上可直接使用；需支援 WebAssembly JSPI 的瀏覽器，已在 Chrome 驗證
      開啟網站→ GitHub ↗
