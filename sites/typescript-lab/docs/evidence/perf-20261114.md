# 頁面載入效能與 CSP 瀏覽器驗收紀錄（2026-11-14）

## 測試環境與邊界

- **測試標的**：本機建置產物（`npm run build` 後由 `vite preview --port 4173 --host 127.0.0.1` 提供服務）。
- **瀏覽器與視窗**：Headless Google Chrome（CDP），`1280x800` 桌面視窗，共量測 7 次載入（第 1 次停用快取模擬冷啟動，第 2–7 次啟用瀏覽器快取模擬暖啟動）。
- **環境限制**：測試於隔離沙盒 VM 執行，對外部網域（`harbor-1wk.pages.dev`、`fonts.googleapis.com`）的連線受代理憑證限制而失敗（`net::ERR_CERT_AUTHORITY_INVALID`），故本次指標反映本機靜態 bundle、Monaco Editor 與 TypeScript worker 資產的載入表現；正式 GitHub Pages 線上環境的外部字型與維護腳本延遲未計入。

## CSP 與 Runner 隔離實測

- **CSP 違規事件（`securitypolicyviolation`）**：`0` 筆（主頁 `index.html` 與獨立 `public/runner.html` 皆無 CSP console error）。
- **課程執行測試（`01-01` 參考解法）**：透過 `iframe[sandbox="allow-scripts"]` 載入 `runner.html` + `runner-bridge.js` 並建立 Blob Worker 執行，回傳 `全部通過，練習完成`（4/4 項檢查通過）。
- **無窮迴圈逾時隔離（自由練習區 `while (true) {}`）**：約 3 秒後由主頁計時器終止 Worker 並移除 iframe，顯示 `執行超過 3 秒，已停止。請檢查無窮迴圈或未完成的 Promise。`。
